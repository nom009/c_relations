# C-Relations

EPC工程を管理する、ブラウザ内保存型のワークスペースです。

## 動作モード

| モード | 有効化 | 保存先 |
| --- | --- | --- |
| ローカル（既定・GitHub Pages） | なし | ブラウザの IndexedDB（端末間同期なし） |
| サーバー | ビルド時に `VITE_STORAGE=api`（任意で `VITE_API_BASE`、既定 `/api`） | サーバー（複数ユーザーで共同編集） |

サーバーモードでは、ログイン（Entra ID）したユーザーがプロジェクトの所有者／編集者／閲覧者として共同編集します。保存は行単位の楽観ロックで、同じタスク・依存関係を同時に変更すると競合ダイアログで「相手の変更を採用」か「自分の変更で上書き」を選びます。他メンバーの変更は約10秒間隔で取り込みます。閲覧者は参照のみ、メンバー管理は所有者のみです（操作メニューの「メンバー…」）。

```sh
VITE_STORAGE=api npm run build   # サーバー版ビルド
npm run dev                      # /api は http://localhost:7071 へプロキシ（API_PROXY_TARGET で変更可）
npm run test:e2e:api             # サーバー版 E2E（API の開発サーバーを自動起動）
```

API サーバーは [../api/README.md](../api/README.md)、Azure へのデプロイ手順は [../docs/azure-deployment.md](../docs/azure-deployment.md) を参照してください。ローカルモードの動作・テストはサーバーモードの有無に影響されません。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
```

概要画面から依存関係、ガント、タスク一覧へ移動できます。新規タスクは「タスクを追加」または N。検索は Cmd/Ctrl+K。詳細パネルで所要日数を変更すると、適用前に完了日への影響が分かります。

初回の21タスクは架空のサンプルです。プロジェクトメニューから空のプロジェクトを作成できます。データはIndexedDBに保存され、端末間同期はありません。同時に編集できるのは1つのタブだけです（別タブで開くと待機画面になります）。バックアップは「データ」からJSONを書き出してください（最終バックアップから7日経過すると起動時に通知します。ブラウザの保存領域が未保護の場合は3日）。読込時に保存データの不整合を検出した場合は、保存履歴から自動復元します。

単体テスト92件。本番ビルドで型検証を実施。PR更新時とmain更新時にGitHub Actionsでテスト・型検証・GitHub Pages向けビルドを自動確認します。E2Eシナリオは更新済みですが、この変更ではブラウザ実行は行っていません。`npm run test:e2e` はテスト専用のストア公開を有効にして検証します。本番ビルドではストアを公開しません。
