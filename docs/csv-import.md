# CSV（Excel）取込フォーマット

画面右上「データ ▾」から次の操作ができます。

| メニュー | 内容 |
|---|---|
| CSVテンプレートを書き出す | 見出し＋記入例の CSV（UTF-8 BOM 付き・Excel でそのまま開ける） |
| CSV（Excel）を書き出す | 表示中のプロジェクトを同じ形式で出力 |
| CSV（Excel）を読み込む… | CSV を **新しいプロジェクト** として取り込む（既存プロジェクトは変更しない） |

## 列

1 行目が見出し、2 行目以降が 1 行 1 タスクです。列の順番は自由、不要な列は削除して構いません。

| 列 | 必須 | 書き方 | 例 |
|---|---|---|---|
| WBS | ○ | 一意な番号。先行タスクの参照に使う | `1.2` / `A-1` |
| タスク名 | ○ | 自由文 | 詳細設計 |
| 分類 | | 設計 / 調達 / 施工 / その他（E / P / C も可）。空欄=その他 | 設計 |
| 所要日数 | | 稼働日数（0 以上）。空欄=0 日（警告） | `15` / `15日` |
| マイルストーン | | `○` でマイルストーン（所要 0 日） | ○ |
| 先行タスク | | 先行の WBS。複数は `,` 区切り。依存タイプとラグを付けられる | `1.1` / `1.2SS+5` / `2.2,3.1` |
| ステータス | | 未着手 / 進行中 / 完了 / 保留。空欄は進捗から推定 | 進行中 |
| 進捗(%) | | 0〜100（`40%`・`0.4` も可） | 40 |
| 担当 | | 自由文 | 設計課 |
| 開始日 | | この日以降に開始（SNET） | `2026/4/1` |
| 期限 | | この日までに完了（FNLT）。開始日とどちらか一方 | `2026/12/25` |
| 備考 | | 自由文（改行可） | 長納期品 |

- 先行タスクの依存タイプ: `FS`（終了→開始・既定）/ `SS` / `FF` / `SF`。ラグは `+2` / `-1`（稼働日）。
- 日付は `2026/4/1`・`2026-04-01`・`2026年4月1日`・`20260401` を受け付けます。
- 見出しは別名も可（例: 作業名・工期・先行・担当者・納期）。
- 取込後のプロジェクト基準日は「開始日」列の最も早い日付（無ければ今日）です。

## 文字コード

UTF-8（「CSV UTF-8（コンマ区切り）」で保存）を推奨します。Excel 既定の「CSV（コンマ区切り）」＝ Shift_JIS も自動判別して読み込めます。

## エラー時

1 件でも誤りがあると取り込まず、`5行目: 先行タスク「1.9」が見つかりません` のように行番号付きで一覧表示します。Excel の行番号と一致するので、その行を直して再度読み込んでください。
