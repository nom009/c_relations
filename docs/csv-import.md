# CSV（Excel）取込フォーマット

画面右上「データ ▾」から次の操作ができます。

| メニュー | 内容 |
|---|---|
| CSVテンプレートを書き出す | 見出し＋記入例の CSV（UTF-8 BOM 付き・Excel でそのまま開ける） |
| CSV（Excel）を書き出す | 表示中のプロジェクトを同じ形式で出力（No・ID 付き） |
| CSV（Excel）から新規プロジェクトを作成… | CSV を **新しいプロジェクト** として取り込む（既存プロジェクトは変更しない） |
| CSV（Excel）で現在のプロジェクトを更新… | 書き出した CSV を Excel で直し、**表示中のプロジェクト** に反映する（[更新取込](#現在のプロジェクトを更新する)。閲覧のみの権限では表示されません） |

## 列

1 行目が見出し、2 行目以降が 1 行 1 タスクです。列の順番は自由、不要な列は削除して構いません（必須は WBS とタスク名）。
書き出し・テンプレートの列順は次のとおりです。

| 列 | 必須 | 書き方 | 例 |
|---|---|---|---|
| No | | タスク番号。**先行タスクはこの番号で指定** します。行ごとに一意（空欄可。ただし空欄の行は先行タスクに指定できない）。書き出し時は 1 から連番 | `3` |
| WBS | ○ | グループ分けのコード。**複数のタスクが同じ値でもよい**（空欄可） | `1.2` / `A-1` |
| タスク名 | ○ | 自由文 | 詳細設計 |
| 工種 | | 設計 / 調達 / 施工 / その他（E / P / C も可）。空欄=その他。見出し「分類」も可 | 設計 |
| 所要日数 | | 稼働日数（0 以上）。空欄=0 日（警告） | `15` / `15日` |
| マイルストーン | | `○` でマイルストーン（所要 0 日） | ○ |
| 先行タスク | | 先行タスクの No。複数は `,` 区切り。依存タイプとラグを付けられる | `1` / `2SS+5` / `4,5` |
| ステータス | | 未着手 / 進行中 / 完了 / 保留。空欄は進捗から推定 | 進行中 |
| 進捗(%) | | 0〜100（`40%`・`0.4` も可） | 40 |
| 担当 | | 自由文 | 設計課 |
| 開始日 | | この日以降に開始（SNET） | `2026/4/1` |
| 期限 | | この日までに完了（FNLT）。開始日とどちらか一方 | `2026/12/25` |
| 実績開始日 | | 実際に着手した日 | `2026/4/3` |
| 実績完了日 | | 実際に完了した日（その日を含む）。実績開始日より前は不可 | `2026/4/30` |
| 備考 | | 自由文（改行可） | 長納期品 |
| ID | | アプリ内部のタスク ID（英数字・`_`・`-`、64 文字以内）。**更新取込の突き合わせに使うので変更しないでください**。新しい行は空欄 | `k3x9…` |

- 先行タスクの依存タイプ: `FS`（終了→開始・既定）/ `SS` / `FF` / `SF`。ラグは `+2` / `-1`（稼働日）。例: `3` / `3FS+2` / `3SS-1日`。区切りは `,` `、` `;` または改行。
- 日付は `2026/4/1`・`2026-04-01`・`2026年4月1日`・`20260401` を受け付けます。
- 見出しは別名も可（例: 番号・タスク番号・`#`・作業名・分類・工期・先行・担当者・納期・実績開始・実績完了）。
- 取込後のプロジェクト基準日は「開始日」列の最も早い日付（無ければ今日）です。

### 先行タスクの参照先（No 列が無い旧形式）

「No」列があれば先行タスクは常に No で読みます。No 列が無い CSV（旧形式）は次の順で読みます。

1. WBS が全行で一意なら、WBS（例: `1.2` / `1.2SS+5`）。
2. WBS が重複していれば、**データ行の順番**（見出しの次の行が 1。エラー行も数える）。この場合は注意を表示します。

迷ったら「No」列を追加して番号で指定してください。

### ID 列

- 新規プロジェクト作成では、ID はすべて振り直されます（取り込み元プロジェクトと衝突しません）。
- 形式が正しくない ID は無視して新しいタスクとして扱い（注意を表示）、同じ ID が 2 行にあるとエラーです。

## 文字コード

UTF-8（「CSV UTF-8（コンマ区切り）」で保存）を推奨します。Excel 既定の「CSV（コンマ区切り）」＝ Shift_JIS、「Unicode テキスト」（タブ区切り）も自動判別して読み込めます。

## Excel で作るときの注意

- **WBS 列は書式を「文字列」にしてください。** 数値のままだと `1.10` が `1.1` に、`1-2` が日付に自動変換され、WBS のグループが変わってしまいます。
- ID 列は Excel が書き換えることはありませんが、並べ替えやコピーで別の行に移さないでください。
- 表の上に表題行があっても構いません（先頭 20 行以内の見出し行を自動で探します）。

## 現在のプロジェクトを更新する

「CSV（Excel）を書き出す」で出力した CSV を Excel で編集し、「CSV（Excel）で現在のプロジェクトを更新…」で読み込むと、表示中のプロジェクトに反映します。反映前に件数（追加 / 更新 / 変更なし / 削除、依存の追加 / 削除）と削除されるタスクを確認ダイアログで表示します。

- タスクは **ID 列** で突き合わせます。
  - ID が一致する行 → CSV の値で更新（位置・作成日時などは保持）。
  - ID が空欄（または現在のプロジェクトに無い ID）の行 → 新しいタスクとして追加。
  - **CSV に無い既存タスク → 削除**（その依存関係も削除）。CSV から行を消すとタスクが消えます。
  - ID 列が無い CSV では突き合わせできないため、全行が追加・既存タスクはすべて削除になります（ダイアログで警告します）。
- CSV に **列が無い項目は既存の値を保ちます**（例: 担当列を消した CSV でも担当は変わりません）。
- 「先行タスク」列があれば、依存関係は CSV の内容に置き換えます（同じ先行・後続の組は既存の依存を保ち、種類・ラグだけ更新）。列が無ければ既存の依存を保ちます。
- タスクを追加したときだけ、反映後に全体整列を行います（追加が無ければノードの配置は変えません）。
- 反映は 1 回の「戻す」で取り消せます（全体整列を行った場合は、整列と反映の 2 回）。
- 変更した行だけが保存・同期の対象になります（サーバー版では他の利用者にも反映されます）。

## エラー時

1 件でも誤りがあると取り込まず（更新取込では現在のプロジェクトを変更せず）、`5行目: 先行タスク「9」が見つかりません` のように行番号付きで一覧表示します。Excel の行番号と一致するので、その行を直して再度読み込んでください。一覧は「コピー」でクリップボードに写せます。
